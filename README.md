# PlaceSim

LLM-based interactive platform for simulating human behavior in physical facilities.

🌐 **Live Demo**: https://simulation-viewer.vercel.app/

📄 **Paper**: [CIKM 2025](https://doi.org/10.1145/3746252.3761461)

## Overview

PlaceSim uses Large Language Models to predict how people will use facilities that don't exist yet. Design spaces, generate AI personas, and watch real-time behavioral simulations—no coding required.

## Quick Start

```bash
git clone https://github.com/suhyeonnnnn/simulation-viewer.git
cd simulation-viewer
npm install
npm run dev
```

Add your OpenAI API key in the web interface.

## Features

- Drag-and-drop facility designer
- AI-powered persona generation
- Live simulation with transparent reasoning
- What-if scenario comparison
- Data export for analysis
